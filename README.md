# РядомДешевле

Минималистичное устанавливаемое веб-приложение для iPhone: поиск товаров по
названию, штрихкоду или фотографии, сравнение опубликованных цен поблизости,
список ближайших магазинов и импорт наличия из CSV.

Приложение работает в браузере и использует открытые данные Open Food Facts,
Open Prices и OpenStreetMap. Если магазин не публикует остатки или дату поставки,
приложение честно сообщает, что наличие неизвестно.
